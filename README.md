# Project-3 Collection Manipulator

###  Introduction
Collection Manipulator is a Python project developed to practice and strengthen the concepts of Python collections and data manipulation.
It includes a Student Data Organizer program that uses different Python collection data types to store and manage student information.
The project allows users to add, display, update, and delete student records through a menu-driven interface.

###  Features
- Add Student
- Prevent duplicate Student IDs
- Display All Students
- Update Student Information
- Delete Student
- Display Subjects Offered
- Exit the program
- Manage student data using multiple Python collections
